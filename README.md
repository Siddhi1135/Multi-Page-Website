# Wanderly 🧳✈️

A responsive multi-page travel booking website built with plain HTML, CSS, and JavaScript.

## Pages
- Home (index.html)
- About (about.html)
- Explore (explore.html)
- Login (login.html)
- Contact (contact.html)

## Running Locally
Open index.html directly in a browser, or use the VS Code Live Server extension for auto-refresh while editing.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Font Awesome icons
- Google Fonts (Inter)
